# 🏛️ Indo-European Gods Network

An interactive, data-driven visualization of the mythological connections between Indo-European deities. Explore how gods across different pantheons share traits, linguistic cognates, and archetypal roles through a dynamic force-directed graph.

![D3.js](https://img.shields.io/badge/D3.js-v7-orange)
![Vanilla JS](https://img.shields.io/badge/JS-ES6_Modules-yellow)

## ✨ Features

- **Force-Directed Graph**: Interactive D3.js network showing connections based on trait similarity.
- **Pantheon Clustering**: Visual grouping of deities by their mythological pantheon (Norse, Greek, Vedic, Celtic, etc.).
- **Trait Highlighting**: Click on specific traits (e.g., *Storm*, *Sun*, *Death*) to highlight related connections.
- **Linguistic Cognates**: Special dashed gold lines indicate deities that share a Proto-Indo-European (PIE) etymological root.
- **Similarity Matrix**: A heatmap view showing the average trait overlap between different pantheons.
- **Guided Tours**: Step-by-step narrative explorations of specific mythological themes.
- **Minimap & Zoom**: Seamless navigation through the network with a real-time minimap and node pinning.

## 🛠️ Tech Stack

- **Frontend**: Vanilla JavaScript (ES6 Modules) - No build step required!
- **Visualization**: D3.js v7 (Force simulation, zoom, transitions)
- **Styling**: Modern CSS (Custom properties, CSS Grid, Flexbox)
- **Data**: Custom JS data structures for deities, traits, and cognates.
